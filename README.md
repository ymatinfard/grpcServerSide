# gRPC Chat Server with Kotlin and Spring Boot

This project is a gRPC-based chat server implemented using Kotlin and Spring Boot. It supports bidirectional messaging and integrates a reactive database (R2DBC) for storing chat messages.

## Features
- **Bidirectional streaming** using gRPC.
- **Kotlin coroutines** for efficient asynchronous processing.
- **Reactive database (R2DBC)** for storing chat messages.
- **Spring Boot integration** for easy server setup.

## Technologies Used
- **Kotlin**
- **Spring Boot**
- **gRPC**
- **R2DBC (Reactive Database Access)**
- **PostgreSQL (or any R2DBC-supported database)**
